# @my-games/zuma-core

> 祖玛引擎核心，纯 TypeScript、无框架依赖。**当前为 `0.0.0` 占位版本**，
> 仅导出占位常量，用于种下 npm 首版并配置 Trusted Publisher。

```bash
pnpm add @my-games/zuma-core
```

```ts
import { ZUMA_PACKAGE, ZUMA_STAGE } from '@my-games/zuma-core';
```

真实引擎（`Zuma` 状态机 + 轨道曲线 + 彩球链模拟 + 发射/瞄准 + 无框架 Canvas 渲染器 + 关卡与存档）将在占位包发布后作为后续提交补入。
产出 ESM / CJS / UMD / IIFE 四格式；IIFE/UMD 全局名 `ZumaCore`。样式：`@my-games/zuma-core/style.css`。

完整说明见仓库根 README：<https://github.com/my-gam/zuma#readme>
